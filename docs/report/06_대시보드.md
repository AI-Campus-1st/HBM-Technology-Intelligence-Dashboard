# 6. 대시보드

> 담당: 공동 (장별 파일이라 동시에 써도 충돌이 적다)

## 6.1 공통 테마 (2026-11-19)

- **결정:** 대시보드 전체를 탭 2(공시 Q&A)에서 먼저 만든 어두운 테마로 맞춘다 (김한승·한도윤 합의). Spotify 디자인 문서(getdesign.md)를 참조했다.
  - 색: 배경 `#121212`, 카드 `#181818`·`#1f1f1f`, 본문 흰색, 보조 글자 `#b3b3b3`. 초록 `#1ed760`은 주요 버튼·활성 상태에만 쓰고, 빨강 `#f3727f`은 거절·부정, 주황 `#ffa42b`은 경고에 쓴다.
  - 모양: 알약 모양 버튼·필터, 테두리 없는 카드(배경 명도 차이로 구분), 검정 사이드바.
- **구현:** 두 곳에 같은 색을 둔다.
  - `.streamlit/config.toml` `[theme]`: Streamlit 기본 위젯과 `st.plotly_chart`(기본 `theme="streamlit"`)가 이 색을 따른다.
  - `dashboard/components/theme.py` `apply_theme()`: config로 바꿀 수 없는 모양(버튼·필터·펼침·사이드바·지표 카드)을 CSS로 넣는다. `app.py`와 모든 페이지가 `st.set_page_config` 바로 다음에 부른다.
  - 페이지 전용 요소는 각 페이지 컴포넌트에 둔다 (탭 2: `qa_view.QA_CSS`).
- **확인:** 메인·이슈 분석·공시 Q&A 세 화면 모두 배경 `#121212`, 사이드바 검정, 공통 CSS 적용을 확인했다. 테스트 `test_common_theme_shared_by_pages_and_config`가 config 색과 모든 페이지의 `apply_theme()` 호출을 확인한다.
