## 6.2 탭 1 — HBM 이슈 모니터링 (김한승, Day 6)

> 코드: `dashboard/pages/1_이슈_분석.py`(배치·필터) → `components/issue_charts.py`(차트·카드) ← `data_access/issue_loader.py`(저장된 결과 읽기)
> 실행: `streamlit run dashboard/app.py` → 왼쪽 메뉴 '이슈 분석'. LLM을 부르지 않고 미리 저장한 결과만 읽는다.

| 구역 | 내용 | 데이터 |
|---|---|---|
| 요약 | 분석 기사 6,953건 중 HBM 385건(5.5%), 급증 구간 4/6(공시로 확인/전체), 감성 정확도 SK 0.78·삼성 0.88(표본 50건), 확인된 근거 공시 15건 | DB, `sentiment_eval_sent_v2.csv` |
| HBM 보도 비중과 급증 구간 | 월별 HBM 비중 선 + 급증 문턱(점선) + 급증 달 점 + 급증 구간 띠(진한 띠 = 공시로 확인, 점선 띠 = 제외). 아래에 월별 HBM 기사 수 막대를 **따로** 둔다 | SQL 02, `hbm_spike_months.csv`, `issue_summary_v1.csv` |
| 급증 구간 살펴보기 | 구간 선택 → 사건 요약(제외 구간은 제외 이유), 구간 기업별 순감성, 대표 기사 8건(원문 링크·기업별 감성·키워드), 사람이 확인한 근거 공시(DART 링크·확인 메모) | DB `news`·`news_analysis`·`issue_evidence`, `issue_evidence_review_v1.csv` |
| 기업별 보도 점유 | 급증 구간별·구간 밖 HBM 기사 중 기업 태그 비율 (가로 막대) | SQL 03 |
| 기업별 감성 추이 | 3개월 순감성 선 (기업 필터 적용) + 급증 구간 띠, 검수 정확도·한계 안내 | SQL 04 (`sent_v2`) |

- **설계 원칙 (차트):** 축은 하나만 쓴다 — 기사 수와 비중은 단위가 달라 차트를 나눴다 (이중 축은 두 선의 교차가 축 비율에 따라 달라져 오해를 만든다). 기업 색은 기업에 고정(SK하이닉스 주황 `#d95926`, 삼성전자 파랑 `#3987e5`)하고, 기업 필터로 한쪽을 빼도 바뀌지 않는다. 두 색은 어두운 배경에서 색각 이상 시뮬레이션 기준으로도 구분된다 (검증 스크립트 ΔE 26.8). 기업과 무관한 HBM 비중은 밝은 회색으로 그려 기업 색과 헷갈리지 않게 했다.
- **신뢰성 표시:** 감성 차트 아래에 LLM 모델·프롬프트 버전·표본 정확도(95% CI)와 '같은 표본으로 규칙을 다듬어 낙관적일 수 있음'을 적었다. 3개월 기사 수가 3건 미만인 달은 순감성을 끊어 그린다. 근거 공시는 사람이 확인한(`verified=1`) 것만 보인다.
- **표로 보기:** 차트마다 숫자 표를 펼쳐 볼 수 있다 (색에 의존하지 않고 값 확인).
- **필터 (2026-11-20, Day 6 종료 조건):** 화면 위 기간(월 범위 슬라이더)·기업(전체/SK하이닉스/삼성전자) 필터를 모든 구역에 같은 기준으로 건다.

  | 구역 | 기간 필터 | 기업 필터 |
  |---|---|---|
  | 요약 지표 | 기간 안 기사·HBM 비중·급증 구간·근거 공시 수로 다시 계산 | (기업 무관 지표) |
  | HBM 비중 선·급증 띠 | 기간만 표시, 축도 기간에 맞춤 | 적용 안 함 — '전체 기사 중 HBM' 지표라 기업과 무관 (캡션 명시) |
  | 월별 기사 수 막대 | 기간만 | 기업을 고르면 그 기업이 나온 HBM 기사 수(기업 색) |
  | 급증 구간 선택지·카드 | 기간과 겹치는 구간만 | 대표 기사 = 그 기업이 나온 기사, 근거 공시 = 그 기업 공시 |
  | 기업 보도 점유 | 기간 안 기사만 다시 집계 (SQL 03과 같은 정의, 전체 기간이면 SQL 03과 같음을 테스트) | 그 기업 막대만 |
  | 감성 추이 | 기간만, 축도 맞춤 | 그 기업 선만 (색 고정) |
  | 표로 보기 | 모두 기간 적용 | 감성 표는 기업 적용 |

  - **카테고리 필터는 두지 않는다:** 분석 범위가 HBM 단독(초안 §11 결정 로그 2026-11-16)이라 기술 카테고리를 고를 대상이 없다. 뉴스 카테고리(기술·공급망·정책)는 3.1절 분포로만 다룬다.
- **테마:** 공통 어두운 테마(6.1, `theme.apply_theme`)를 쓰고, 지표·카드 모양은 탭 2의 `.qa-*` CSS를 재사용해 두 탭의 모양을 맞췄다 (`qa_view.apply_theme()` = 공통 테마 + `.qa-*`). 차트 글자·축 색은 어두운 배경(`#121212`)에서 읽히도록 직접 지정했다.
