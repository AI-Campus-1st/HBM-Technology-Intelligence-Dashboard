# 1. 분석 목적

> 담당: 공동 · 작성: Day 1 초안, 초안 v1.2 기준으로 갱신 (최종 리포트 작성 시 실측 수치로 보완)

## 1.1 기획 배경

AI 반도체 수요가 늘면서 HBM(고대역폭 메모리)이 메모리 업계의 핵심 경쟁 축이 되었다. SK하이닉스와 삼성전자에 대한 HBM 보도는 많지만 중복·재배포가 많다. 그래서 어떤 시점에 무엇이 변했는지, 그 변화가 각 기업의 공개된 연구개발·투자 활동과 어떻게 연결되는지 판단하기 어렵다.

이 프로젝트는 **HBM 이슈 비중 변화 → 급증 시점 탐지 → 기업별(SK하이닉스·삼성전자) 보도·감성 비교 → 공시 근거 확인**이라는 분석 흐름을 구현한다.

## 1.2 대상 산업과 기업

| 항목 | 내용 |
|---|---|
| 산업군 | 반도체 |
| 대상 기업 | **SK하이닉스** (비교: **삼성전자**) — 두 기업 모두 DART 공시 수집 |
| DART 고유번호 | SK하이닉스 `00164779` · 삼성전자 `00126380` (`src/dart/corp_code.py`로 확인) |
| 분석 기술 범위 | **HBM 단독 분석 권장.** 첨단 패키징·DRAM은 제목 기사가 적어 독립 분석이 어렵고, HBM 기사 안의 보조 정보로만 사용 검토 |
| 뉴스 데이터 | 제공 반도체 묶음 7,177건 (`04_반도체_묶음`, 81개 매체) |
| 뉴스 키워드 | `반도체 R&D`(기술 및 트렌드) · `반도체 밸류체인`·`반도체 원자재`(공급망 및 인프라) · `반도체 수출 통제`·`반도체 세제 혜택`(규제 및 정책) |
| 분석 기간 | **2023-10-19 ~ 2026-10-19** (뉴스 수집 기간 전체, 가이드 권장 최근 3년). 뉴스·공시 동일 기간 |
| 집계 단위 | 월별 (월별 기사 중앙값 169건, 주별은 34건으로 너무 적음) |

**선정 이유**
- 반도체는 수출 규제·공급망·설비투자 이슈가 뉴스와 공시 양쪽에서 확인되는 산업이다.
- SK하이닉스는 HBM 시장의 핵심 기업이면서 국내 상장사라 DART 공시로 R&D·투자 정보를 확인할 수 있다.
- 단일 기업만으로는 '경쟁' 구도를 설명할 수 없어 HBM의 주요 경쟁사인 삼성전자를 비교 기업으로 추가했다.

**커버리지 확인 (Day 1, 규칙 기반 1차 집계 `regex_v1`):** HBM 제목 기사 205건, 핵심+관련 1,118건으로 분석 진행(GO). 다만 분기당 HBM 제목 기사가 1~46건이라 수치 해석에 주의한다.

## 1.3 대시보드 사용자

| 구분 | 내용 |
|---|---|
| 핵심 사용자 | **증권사 반도체 담당 애널리스트** *(가상 페르소나)* |
| 업무 상황 | 메모리 업체 실적·전략 리포트 작성 전, HBM 경쟁 구도의 변화와 근거 자료를 정리 |
| 해결할 문제 | 기사가 많고 중복 보도가 많아 "언제, 왜, 누구에게 유리하게" 이슈가 바뀌었는지와 공시 근거를 찾기 어려움 |
| 필요한 결과 | HBM 이슈 비중 추이, 급증 사건, 기업별 보도·감성 비교, 공시상 확인 사실, 확인 불가 항목 |
| 사용 범위 | 공개자료 기반 기술 인텔리전스. 투자 의견·목표주가는 제시하지 않음 |

**페르소나 선정 근거:** 처음에는 SK하이닉스 사내 기술전략 담당자를 가정했지만, 사내 담당자는 공개 뉴스보다 좋은 내부 정보를 가지고 있어 공개자료 대시보드의 사용자로 맞지 않았다. 뉴스·DART 공시·경쟁사 비교가 실제 업무 흐름과 일치하는 애널리스트로 바꿨다. 기관투자자와 협력사 전략기획 담당자는 필요한 데이터(주가, 고객사별 발주)가 범위 밖이라 확장 사용자로만 언급한다.

## 1.4 핵심 질문

**메인 질문:** HBM 경쟁에서 SK하이닉스와 삼성전자에 대한 시장의 관심과 이슈는 시기별로 어떻게 달라졌으며, 공시로 확인되는 대응과 애널리스트가 추가로 확인해야 할 기회·위험 신호는 무엇인가?

**보조 질문**
1. HBM 관련 보도 **비중**은 언제 급증하고 둔화했는가? 급증 시점의 대표 사건은 무엇인가?
2. 같은 기간 SK하이닉스와 삼성전자의 HBM 보도 점유율과 감성은 어떻게 달랐는가?
3. 두 기업의 공시에서 확인되는 R&D 활동·투자·제품 정보는 무엇이고, 확인할 수 없는 부분은 무엇인가?

## 1.5 목표와 성공 기준

**목표:** 최근 3년(2023-10-19 ~ 2026-10-19) 반도체 뉴스와 SK하이닉스·삼성전자 DART 공시를 통합 분석하여 HBM 이슈의 비중 변화와 급증 시점을 탐지하고, 기업별 보도·감성 차이와 공시 근거를 비교한다. 이를 통해 근거와 한계를 명시하는 애널리스트용 기술 인텔리전스 대시보드를 구축한다.

**성공 기준:** 사용자가 HBM 이슈의 변화, 변화가 나타난 이유, 기업별 차이, 연결 가능한 공시 근거, 추가 확인이 필요한 사항을 한 화면 흐름에서 파악할 수 있다.

**주요 판단 기준 (Day 1 확정)**
- 관심도: HBM 관련 기사 수 ÷ 같은 달 전체 기사 수
- 관련도: 핵심(제목에 HBM) / 관련(본문 5회 이상) — 기본 분석은 핵심+관련
- 급증 구간: 월별 HBM 비중이 직전 6개월 평균 + 2σ를 넘는 달, 연속된 달은 한 구간 (최소 기사 수 조건은 Day 3 EDA 후 결정)

## 1.6 해석 원칙

1. 기사 **절대량이 아니라 비중**으로 관심도를 판단한다. 전체 수집 기사 수가 분기마다 크게 달라서 절대량만 보면 정점을 잘못 읽는다.
2. 보도 점유율·감성 ≠ 실제 시장 점유율·사업 성과
3. 기업 전체 R&D 지출액 ≠ HBM 투자액. 사업 구조가 다른 삼성전자와 전체 수치를 직접 비교하지 않는다.
4. 같은 시점에 뉴스·공시가 있다고 두 사건의 인과관계가 성립하지 않는다.
5. 첫 달(2023-10, 13일분)과 마지막 달(2026-10, 19일분)은 일부 기간만 있으므로 월별 비중 해석 시 표시한다.
