# 1. 분석 목적

> 담당: 공동 · 작성: Day 1 초안 (최종 리포트 작성 시 실측 수치로 보완)

## 1.1 기획 배경

반도체 분야에서는 HBM, 차세대 DRAM, 첨단 패키징 등 기술 관련 보도가 계속 나온다. 하지만 뉴스만으로는 어떤 이슈가 실제로 두드러지는지, 그 이슈가 SK하이닉스의 공개된 연구개발·투자 활동과 어떻게 연결되는지 판단하기 어렵다.

이 프로젝트는 **뉴스의 기술 이슈 변화 → 급증 시점 탐지 → 공시 근거 확인 → 전략 검토용 요약**이라는 분석 흐름을 구현한다.

## 1.2 대상 산업과 기업

| 항목 | 내용 |
|---|---|
| 산업군 | 반도체 |
| 대상 기업 | SK하이닉스 |
| 분석 기술 범위 | 우선: HBM·차세대 고대역폭 메모리 / 보조: 첨단 패키징·적층, 차세대 DRAM |
| 뉴스 키워드 | `반도체 수출 통제`, `반도체 세제 혜택`, `반도체 R&D`, `반도체 밸류체인`, `반도체 원자재` |
| 기간 | 최근 3년 (뉴스·공시 동일 기간) |

**선정 이유:** 반도체는 수출 규제·공급망·설비투자 이슈가 뉴스와 공시 양쪽에서 확인되는 산업이다. SK하이닉스는 HBM 시장의 핵심 기업이면서 국내 상장사라 DART 공시로 R&D·투자 정보를 확인할 수 있다.

> 제공 뉴스가 HBM·첨단 패키징·차세대 DRAM을 충분히 포함하는지는 아직 확인 전이다. 기사 분포에 따라 기술 세부 범위를 조정한다.

## 1.3 대시보드 사용자

| 구분 | 내용 |
|---|---|
| 핵심 사용자 | SK하이닉스 기술전략팀의 산업·경쟁 동향 분석 담당자 *(가상 페르소나)* |
| 업무 상황 | 외부 기술 동향을 모니터링하고 R&D 전략 검토를 위한 사전 분석 자료 작성 |
| 해결할 문제 | 기사량이 많고 중복 보도가 많아 중요한 변화의 시점과 근거 확인이 어려움 |
| 필요한 결과 | 기술별 관심도 변화, 급증 사건, 공개된 기업 활동, 근거 문서, 불확실성 |
| 사용 범위 | 공개자료 기반 기술 인텔리전스. 사내 R&D 투자 의사결정 자체를 대체하지 않음 |

## 1.4 핵심 질문

**메인 질문:** HBM 중심의 AI 반도체 기술 경쟁에서 SK하이닉스가 주목해야 할 기술적 기회와 위험은 무엇인가?

**보조 질문**
1. HBM 기술 이슈가 언제 급증했는가?
2. 급증 시점에 해당하는 뉴스 사건은 무엇이며, 재배포·중복 영향은 얼마나 되는가?
3. 관련 SK하이닉스 공시에서 확인할 수 있는 R&D 활동·투자 정보는 무엇이고, 확인할 수 없는 부분은 무엇인가?

## 1.5 목표와 성공 기준

**목표:** 최근 3년간 반도체 산업 뉴스와 SK하이닉스 DART 공시를 통합 분석하여 HBM 기술 이슈의 변화와 급증 시점을 탐지하고, 공개된 연구개발 활동·투자 정보와 비교한다. 이를 통해 근거와 한계를 명시하는 기술전략 검토용 AI 대시보드를 구축한다.

**성공 기준:** 사용자가 주요 기술 이슈의 변화, 변화가 나타난 이유, 연결 가능한 공시 근거, 추가 확인이 필요한 사항을 한 화면 흐름에서 파악할 수 있다.

## 1.6 해석 원칙

1. 기업 전체 R&D 지출액 ≠ HBM 등 개별 기술 투자액
2. 기사량 증가 ≠ 기술 중요도 또는 사업성과 증가
3. 같은 시점에 뉴스·공시가 있다고 두 사건의 인과관계가 성립하지 않음
4. 뉴스 감성 ≠ SK하이닉스의 사업 영향
5. 비공개 사내 R&D 데이터가 없으므로 실제 투자 최적화는 분석 범위 밖
