## 내린 판단과 근거 (리포트·회고용)
| 판단 | 근거 |
|---|---|
| 재정렬 점수는 21~23/24 범위로 적는다 | 같은 근거로도 LLM이 실행마다 다른 출처를 고른다. 한 번의 숫자로 적으면 우연한 결과를 성과로 보이게 한다 |
| temperature 0(추론 끄기)은 적용하지 않는다 | 흔들림이 남고(Q16 2/4), 추론을 끄면 다른 모델 설정이라 기본·v2·예시 결과를 모두 다시 내야 한다. 거절 판단도 바뀔 수 있다 |
| Q18 정답 근거는 고치지 않는다 | 같은 사실이 다른 공시에 있지만, Q10에 이어 결과를 보고 정답을 고치는 일이 반복되면 과적합이 된다. 리포트에 사례로만 적는다 |
| 평가에서 재정렬은 한 번만 | 재정렬 모델은 같은 입력에 같은 점수를 낸다. 두 번 하면 시간만 두 배다 (Q16·Q18에서 직접 확인) |
| 재정렬은 선택 기능(기본 꺼짐) | CPU에서 질문당 약 40초, 비교 질문 약 108초. 발표에서는 저장된 예시 답변으로 보여 준다 |
| requirements는 `==`로 고정 | 두 컴퓨터의 설치 버전이 다르면 결과가 달라질 수 있다 (pandas 3.1.1 등) |

## 문제 / 상대에게 공유할 것
- **김한승 확인 필요:** requirements 버전 고정에서 `requirements/issue.txt`(김한승 담당, `openai==3.50.0`)와 `requirements/common.txt`(공동, PR 합의)도 바꿨다. 다른 버전을 쓰고 있으면 알려 주고, 괜찮으면 `pip install -r requirements.txt`를 다시 실행한다
