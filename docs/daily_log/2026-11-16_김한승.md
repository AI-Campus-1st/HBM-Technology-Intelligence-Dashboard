## 문제 / 상대에게 공유할 것
- **macOS에서 zip을 풀 때 `data` 폴더가 통째로 교체됨:** Finder로 `data` 폴더를 옮기며 "대치"를 누르면 병합되지 않고 기존 폴더가 사라진다. 뉴스 CSV(git 미포함)를 다시 받아야 했다. git에 있던 라벨 파일은 `git checkout -- data/`로 복구.
  - **한도윤:** zip 안 README 실행 방법에 macOS 주의 문구 추가 제안 — "Finder '대치' 금지, `Option` 드래그로 '병합' 또는 `unzip -n <zip>` 사용"
- **NFD 파일명:** 다시 받은 뉴스 CSV도 NFD 이름. Mac에서는 문제없이 읽히지만 파일을 공유할 때는 README의 NFC 변환 명령 사용.
- **사람 검수 결과로 분석 대상 정밀도가 0.95 → 0.83으로 바뀜:** 대시보드·리포트에 이전 수치를 쓰지 않도록 주의. 결정 로그와 리포트 2.5는 수정 완료.
- **나머지 검수 140건(HBM 핵심·언급, 기업 태그)은 Claude 1차 판정:** 리포트에서 이 층의 정밀도를 사람 검수 결과처럼 쓰지 않는다.
- **PR 쌓기 주의 (한도윤 일지 공감):** 앞으로 base는 항상 `main`, 앞선 PR이 머지되면 다음 브랜치를 `main` 기준으로 rebase.
- 머지된 원격 브랜치 정리 필요 (`issue/day2-news-load`, `issue/tag-label-review` 등) — 저장소 설정 "Automatically delete head branches" 켜기 제안.
